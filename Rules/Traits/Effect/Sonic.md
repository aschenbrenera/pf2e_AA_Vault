# Sonic

A sonic effect might deal [[Sonic Damage]].

## Mechanical Rules

- An effect with the sonic trait functions only if it makes sound, meaning it has no effect in an area of silence or in a vacuum.
	- This is different from an auditory spell, which is effective only if the target can hear it.
