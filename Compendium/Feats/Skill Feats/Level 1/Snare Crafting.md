# Snare Crafting &emsp;*(Feat 1)*

[General](General.md "Feat Trait") [Skill](Skill.md "Feat Trait") 
**Description:** You can create snares. 

**Prerequisite:** Trained in [[Crafting]].

## Mechanical Rules

- You can use the [[Craft]] activity to create [[Snares]].
- When you select this feat, you immediately add the formulas for four common 1st-level snares to your formula book.
